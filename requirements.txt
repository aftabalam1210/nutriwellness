# NutriVerse by Shreya - Requirements & Installation Guide

This project is built using React, Vite, and Node.js. 
To run this application on any machine, please follow the steps below.

============================================================
⚡ QUICK START (ONE-LINE COMMAND)
============================================================
Copy and paste this single command into your terminal to clone the project, install all packages, and start the developer server:

• For Git Bash / Command Prompt / macOS / Linux:
  git clone https://github.com/aftabalam1210/nutriwellness.git && cd nutriwellness && npm install && npm run dev

• For Windows PowerShell:
  git clone https://github.com/aftabalam1210/nutriwellness.git; cd nutriwellness; npm install; npm run dev

============================================================
1. PREREQUISITES
============================================================
You need the following software installed on the machine:
- Node.js (v18.0.0 or higher recommended)
  Download from: https://nodejs.org/
- npm (usually comes bundled with Node.js)
- Git (optional, for cloning the repository)

============================================================
2. INSTALLING NODE DEPENDENCIES
============================================================
Navigate to the project directory in your terminal and run:

  npm install

This command automatically installs all the required Node packages specified in package.json:
  - react (v19.2.0)
  - react-dom (v19.2.0)
  - react-router-dom (v7.12.0)
  - framer-motion (v12.26.2)
  - lucide-react (v0.562.0)
  - devDependencies (vite, eslint, etc.)

============================================================
3. RUNNING THE DEVELOPMENT SERVER
============================================================
To start the project locally, run:

  npm run dev

Once started, open your browser and navigate to:
  http://localhost:5173/

============================================================
4. BUILDING FOR PRODUCTION
============================================================
To compile and bundle the project for production deployment, run:

  npm run build

This generates optimized static HTML/JS/CSS assets inside the "dist/" folder.
